# Daily intent-reply routine — 30 minutes

Inbound interception for AxisForge Labs. No cold outreach. No LinkedIn posts.

## Morning block (20 min) — Reddit + HN

1. **Open F5Bot alerts** (5 min) — triage using [F5BOT-KEYWORDS.md](./F5BOT-KEYWORDS.md) scoring.
2. **Pick 2 threads** where you can write a complete, helpful answer (10 min).
3. **Draft with AI, edit in your voice** (5 min):
   - ChatGPT/Claude prompt: *"I'm an operator who ships fixed-scope automations. Write a helpful Reddit comment answering this question. No sales pitch. Include concrete steps and stack suggestions. Thread: [paste]"*
   - Remove hype. Add one specific detail from your case studies.
4. **Post** — link only if directly relevant (offer page or scope estimator).

### Answer template (adapt, don't copy-paste)

```
[Empathize with their situation in one sentence]

What worked on similar builds:
1. [Concrete step — e.g. classify before generating drafts]
2. [Stack — e.g. Gmail API + Slack webhook + cron]
3. [Timeline band — e.g. 4–5 days for single integration]

[Optional, only if fit]: We productized this shape at fixed scope — [offer URL]. Happy to answer follow-ups here.
```

## Midday block (10 min) — X reply engine

Search on X (no followers needed):

- `"need a developer"`
- `"Zapier" broken OR alternative`
- `"backlog" ship`
- `"internal tool"`

**Reply to 5 posts** with 2–3 sentences of real advice. Link in at most 1 of 5 replies.

- Lead with "We at AxisForge Labs..."
- DM people who didn't ask for help
- Spend time on LinkedIn feed posts (300 connections — low ROI)
